# Greena Foods Website

Starter website based on the supplied design.

## Files
- `index.html` — page structure
- `css/style.css` — full styling + responsive layout
- `js/main.js` — products, mobile menu and quote buttons
- `images/` — put your product/hero images here

## Images to add
Put these files inside `images/`:
- hero-vegetables.jpg
- broccoli.png
- cauliflower.png
- green-beans.png
- strawberries.png
- mango.png
- molokhia.png
- green-peas.png
- spinach.png
- mixed-vegetables.png

If a product image is missing, the site displays an emoji placeholder so the layout still works.

## GitHub Pages
